## 一、需要你拍板的 4 项产品决策

这 4 项是 AI-PM 已按最优解处理、但属于**产品价值判断**而非逻辑推导，需要你确认或推翻。

### 决策 1 ★最重要：脱敏病例怎么评分？

**冲突**：R1 表维度一（14 分）要评"患者信息（姓名、年龄、性别、科别）"和"住院/门诊号、检查号、就诊卡号、影像号正确"，但我们又要对真实病例**脱敏**。脱敏之后，学生看到的就不是真值了，"号码正确"无从判定——**评分引擎没法实现**。

**AI-PM 的处理口径**：

| 字段 | 下发形态 | 怎么评 |
|---|---|---|
| 姓名 | `张*` | **脱敏形态即评分基准**，学生照实复述即得分 |
| 年龄 | 改成**年龄段**（"50–59 岁"） | 同上 |
| 性别 / 科别 | 原样 | 同上 |
| 检查号 / 影像号 | 保留**后 4 位**（`****1234`） | 同上 |
| 住院号 / 就诊卡号 | **全掩**（`****`） | **不可评** → 该项分值剔除，按"实得分 / 可评总分 × 维度满分"**归一折算**，不计 0 分 |
| 临床主要信息及检查目的 | 原样（临床申请信息） | 可评，但**整段照抄不得满分**（须规范转述） |

**需要你确认**：这个口径是否可接受？特别是"全掩字段归一折算"——它会让满分仍是 100 分，但维度一实际只评了 12 分。**是否需要跟院方对一下**（见第四节 Q2）。

### 决策 2：训练流程的组织形态

**AI-PM 的处理**：训练做成**五阶段推进 + 三级提示阶梯**。

- 五阶段：**T0 阅片 → T1 检查技术 → T2 影像所见 → T3 诊断意见 → T4 提交与自评**（可回退到已完成阶段，不可跳过）
- 三级提示（学生主动请求，点一次深一级，也可直接要 L3）：

| 级别 | 给什么 | 例（学生漏了"重要阴性征象"） |
|---|---|---|
| L1 体裁提示 | 这段**规范上**应包含哪些要素，完全不涉及本病例 | "影像所见建议覆盖：部位与范围、数目与大小、形态与边界、密度/信号/强化程度、重要阴性征象" |
| L2 指向提示 | 指出本病例**还缺哪一类** | "本病例的影像所见中，'重要阴性征象'一类尚未涉及" |
| L3 要点提示 | 给该类**要点词**，仍不给金标准原句 | "可关注：病变周围有无肿大淋巴结、有无胸腔积液、有无骨质破坏" |

- 配额：L1 不限；**L2 每段每回合 3 次**；**L3 每段每回合 1 次**；同级冷却 **10 秒**；**重写不重置配额**（新回合才重置）
- 提交后**先自评再看对照**（自评表按 R1 表 23 条目逐条，条目 + 分值全显示），防"一看答案就失去训练意义"

**需要你确认**：五阶段是否太碎（能不能简化为"影像所见 / 诊断意见"两段）？配额数字是否合适？

### 决策 3：对需求 E2-7 的有条件偏离

**需求原文**：「两模式复用同一批影像样本与同一份金标准报告，考核以金标准为评分依据；**金标准仅训练模式可见，考核模式绝不可泄漏**」

**AI-PM 的处理**：允许组卷老师在**交卷后**用任务级开关（`revealGoldStandardAfterSubmit`，**默认关**）向学生露出金标准原文。依据是你 2026-09-19 的决策"做成任务配置，老师组卷时选"。约束：**开关只对已交卷的 attempt 生效，作答期间无论如何不露**。

**需要你确认**：这条要**回写需求确认单**，否则后续验收时可能被按 E2-7 判为"未实现"。是否同意？

### 决策 4：考核派发依赖教师端（排期风险）

**AI-PM 的处理**：按你的要求，考核侧改为「**我的考核任务**」——学生不自选病例，等老师创建考试后派发。本模块只定**数据契约**，派发界面归教师端（任务单第 5 项）。

**风险**：这是**硬依赖**——教师端派发能力没做出来，考核侧就是空壳（PRD 风险点 R7）。

**需要你确认**：教师端排期能否与本期对齐？（见第四节 Q10）若不能，是否本期先只交付训练侧、考核侧留接口？

## 三、AI-PM 已发现的、你可能没注意到的两件事

### 1. 需求草图里的"三视图"和任务单第 6 项是同一套东西

任务单的对齐提醒 2 已写明：**报告书写模块的影像显示控件 = 影像教学底座（Web PACS）**。本期把它当**黑盒组件**处理，只约定接口契约（PRD §9.4），底座可以另起一条线并行做。但**两边要一起排期**。

### 2. 需求确认单里的"待明确 5 项"里，有两项会直接影响架构

- **Q2 影像样本与金标准报告由谁提供**（例数、病种、格式）→ 决定样本库规模与数据接入方式。PRD 按"可配置导入"设计，先用 2–3 例跑通，但不锁死来源。
- **Q3 考核评分规则**（逐项 vs 评级）、是否计时、是否可重考、成绩是否入库 → 决定评分引擎形态。PRD 按 R1 表设计骨架 + 附备选方案。
