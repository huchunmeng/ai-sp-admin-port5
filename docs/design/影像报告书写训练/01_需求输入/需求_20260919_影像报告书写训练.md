## 三、需求条目化（E2 明细 7 条）

| # | 要求原文 | 结构化理解 | 优先级 |
|---|---|---|---|
| E2-1 | 系统内置若干例影像数据，列表形式，点击打开 | 样本库为**内置静态数据**（非 PACS、非实时调阅），入口为**列表页** | P0 |
| E2-2 | 影像以三视图方式显示 | 影像显示控件=**轴位/冠状位/矢状位**三窗；本期为基础浏览，进阶能力属影像教学底座 | P0 |
| E2-3 | 提供学生报告输入控件 | 学生**自行书写**结构化/半结构化影像报告 | P0 |
| E2-4 | 右侧培训提示栏：接通用文本大模型，以金标准报告为参照，针对学生所写内容给提示 | **提示引擎**：输入=金标准报告 + 影像信息 + 学生当前文本；输出=针对性提示 | P0 |
| E2-5 | 提示词后台可配置 | 提示模板与策略为**运营端可配置项**，改策略不改代码 | P0 |
| E2-6 | 训练模式提示常显、边写边提示；考核模式不给提示 | **双模式分流**：同一工作台，提示能力按模式开关 | P0 |
| E2-7 | 两模式复用同一批影像样本与同一份金标准报告，考核以金标准为评分依据 | **一套样本两处复用**；金标准**仅训练模式可见**，考核模式绝不可泄漏 | P0 |
