## 变更 8 · 不可评改为「子项级」，取消归一折算与发布门禁

PRD 附录 E 的兜底原则本就写"只归一**子项**"，但原型演示取"最坏情形"按**整条 −4** 计，
导致学员写对 `FIND-06` 的"密度=实性"、`FIND-04` 的"数目"也白丢分。现改为**逐要点判定**：
`条目可评满分 = 条目满分 × 可评要点数 / 要点总数`。

**连带结论：折算那套机制可以不要了。** 既然能逐要点精确剔除，就**如实显示"本卷可评分 87"**即可，
不必归一折算到 100（那等于"考一张更短的卷"却显示满分，牺牲跨卷可比性）。

| 项 | 原 | 现 |
|---|---|---|
| 不可评粒度 | 整条剔除（−4 / 条） | **逐要点剔除** |
| 可评分 | RC-001/002 = 84，RC-003 = 96 | RC-001 = **87**，RC-002 = **87.7**，RC-003 = **97** |
| 归一折算 | 实得分 ÷ 可评总分 × 100 | **训练侧不折算**，如实显示 `得分 / 本卷可评分` |
| `<85` 发布门禁 + 覆盖审计 | 需要 | **可砍**（那是考务级严谨性；课堂练习用不上） |

| # | 文件 | 位置 | 要改什么 |
|---|---|---|---|
| 8.1 | PRD | §5.2.2 能力位 / 附录 E 不可评条目表 | 明确"**子项级**"判定；给出各样本新可评分 |
| 8.2 | PRD | §5.5.1 `scoreableMax` 与「为何取 85」 | 改为"不折算、如实显示"；`<85` 门禁按决策保留或去掉 |
