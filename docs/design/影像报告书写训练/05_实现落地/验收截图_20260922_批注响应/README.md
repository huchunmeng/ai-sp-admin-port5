## 0.5 第三批批注 ——「练习的成绩报告，应该保留练习记录（我说的是练习考）」

**问题**：练习考原先只把成绩写进考试会话（localStorage 的 `__practice__`），**出分即散** ——
「训练记录」列表里看不到，考完就找不回来了。

**改法**：练习考交卷后，把成绩落进**与训练工作台同一份**练习记录（同一个 key），
所以练习考的成绩报告以后能回看；正式考核**不进**练习记录（它的成绩在考核服务与「成绩管理」里）。

| 位置 | 改动 |

## 2. 批注 2 ——「测量无法点击，无法使用」

> 批注原文：（锚在「缩放」按钮上）测量无法点击，无法使用

**根因**：`canMeasure` 原先要求「该序列有 `PixelSpacing`」，而胸部 CT 是 **JPEG 序列**（没有 `raw`/间距）
→ 按钮被**禁用**。不是坏了，是被设计成"没有间距就不给测"。

**改法**：**没有像素间距时按像素测量，不再禁用**；有间距时仍然是毫米（口径不变）。

| 场景 | 改动 |
|---|---|
| 判定 | `canMeasure` = 有画面即可测（`hasRaw \|\| currentImage`），只有 16-bit 解码不可用（O5 降级）才禁用 |
| 坐标换算 | 新增 `imgEl` + `imgNatural` + `viewSize`：JPEG 用 `<img>` 的自然尺寸换算，不再假设只有 canvas |
| 单位 | `measureUnit`：有间距 → `mm`，无间距 → `px`；标注与底部结果条都带单位 |
| 提示 | `measureTitle` 分三种：正常毫米 / 无间距按像素 / 16-bit 解码不可用 |
| 数据字段 | 测量对象由 `{mm}` 改为 `{len, unit}`（避免字段名叫 mm 实际是 px） |

实测：

```
JPEG 序列（PUB-001，<img> 渲染）：按钮 disabled=false · 拖出 "18 px"
16-bit 序列（KNEE-001，canvas）  ：按钮 disabled=false · 拖出 "126.1 mm"  ← 毫米口径未受影响
考试室（练习考，胸部 CT）        ：按钮 disabled=false · 拖出 "18 px"
```
