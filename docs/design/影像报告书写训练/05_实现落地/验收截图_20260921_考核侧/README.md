## 2. 关键验收点与实测结果

| 验收点 | 结果 |
|---|---|
| 任务配置驱动（题量/时长/达标线/成绩可见性） | ✅ 须知与作答页文案随任务配置变化 |
| 断线续答（4 个端内行为） | ✅ 作答中刷新后仍在考试中、草稿逐字保留、倒计时**接着走**（19:57 → 19:54，不回到 20:00） |
| 考站机断线续答 | ✅ 刷新回登录态 → 重新登录**自动续考**，计时不重置 |
| 交卷即刻锁卷 | ✅ 先落答卷再评分；交卷后立刻刷新是"已交卷"，不会回到作答态 |
| `afterWindow` 成绩锁定 | ✅ 已交卷页与任务列表都显示"成绩将于考试窗口结束后公布"，**无「成绩报告」按钮** |
| `afterSubmit` 成绩可见 | ✅ 正常出分 + 有「成绩报告」按钮 |
| 红线 R1（不给答案） | ✅ 成绩报告无「报告对照」页签；无金标准下发 |
| 重考策略 `single` | ✅ 考站机再次登录同一考生被拒："该考生本场已交卷，不允许重考" |
| 真实影像渲染（16-bit 窗宽窗位） | ✅ canvas 有真实灰阶（非占位），KNEE-001 6 序列可翻层、可测量 |
| 浏览器控制台无报错 | ✅ 上述所有流程 pageerror 均为 0 |

## 3. 复现方式

```bash
# 学员端（在线考试）— 5001
npm run dev:training --prefix apps/training
#   在线考试入口 → 影像报告书写考核 → 我的考核任务
#   或直达 http://localhost:5001/#/report-writing/exam-tasks

# 考试端（现场考站机）— 5003
npm run dev:exam --prefix apps/exam
#   直达 http://localhost:5003/#/report-writing
#   学号/工号 2026001 · 考试码 S03（原型内置名单，见 ReportWritingStation.vue 顶部）
```

> 原型阶段计时以本机时间为准、会话存 localStorage；**正式考核必须由服务端签发
> `startedAt`/`deadline`**，替换点只有 `packages/shared/imaging-ui/useExamSession.js` 的 `EXAM_SERVER`。
