# 能力位评估：留着有用吗？可以去掉吗？（2026-09-20）

> 起因：老胡问「**能力位留着有用吗？可以去掉吗？**」
> 本页是把**当前 16 例可练样本**跑一遍得到的实测数据，用来回答这个问题。**代码未改。**

---

## 一、先说结论

| 问题 | 答案 |
|---|---|
| 设计上有用吗？ | **有用**。它是"**这道题没给条件**"的唯一载体，没有它就只能把这些要点按 0 分算 |
| 当前实现好用吗？ | **半失效**。5 个位里只有 1 个有区分度，而且它的规则**基本没生效**（见第三节） |
| 可以去掉吗？ | **能删，但不能只删模块**。分母改成固定 100 后，每个学员白丢 9–13 分（写得再好也到不了满分），必须同时在评分表里把这些条目逐条标"不适用"——**等于把同一件事从"5 个勾选"换成"逐条标注"，工作量更大**，而且容易退回"整条剔除"的老毛病 |
| 建议 | **留着，做两件实事**：① 面板 5 位瘦到 3 位 ② 把"靠要点文字正则匹配"改成"要点自带可评性标签"。详见第五节 |

## 三、★ 关键发现：5 个位里只有 1 个有区分度，而它的规则没生效

| 能力位 | true | false | 有区分？ | 实际影响 |
|---|---|---|---|---|
| 测量 `hasMeasurement` | 0 | 16 | ❌ 全同 | 位本身不起作用；`FIND-04` 被剔除是因为**规则命中要点文字**，不是因为它 |
| 既往 `hasPriorExam` | 0 | 16 | ❌ 全同 | 位本身不起作用（无样本声明有既往片） |
| **增强** `hasEnhancedPhase` | 5 | 11 | ✅ | **唯一有区分**，但请看下面 |
| 肿瘤 `isTumor` | 7 | 9 | ✅ | 两个分支**同样剔除 `IMP-05` 的 4 分**，对分数零影响，只影响显示的理由（"不适用" vs "缺能力位"） |
| 分期 `hasStagingInfo` | 0 | 16 | ❌ 全同 | 位本身不起作用 |

### 为什么「增强」位区分了却没用？

规则是这样匹配的（`rubric.js` 的 `POINT_RULES`）：`match` 是一个**正则**，去匹配要点的 `id + text`。也就是说，
**能力位能不能生效，取决于 AI 抽取出来的要点措辞里有没有那个关键词**。

实测三条：

| 样例 | 是否增强 | `FIND-06` 的要点（AI 抽取的） | 规则命中？ |
|---|---|---|---|
| PUB-001 | 否 | `描述为'软组织密度'` / `明确否定钙化与空洞` | ❌ 没有"强化"，不剔除 |
| SEU-001 | 是 | `提及病灶紧贴膈面` ← **这条根本不是密度描述** | ❌ |
| SEU-005 | 否 | `描述晕征（结节周围磨玻璃样渗出影）` | ❌ 没有"强化" |

`FIND-04` 同样的问题，而且更难看：同样是 `hasMeasurement = false`，

- SEU-005 的要点是 `提及结节大小（含近似数值或范围）` → **命中**，扣 4 分
- PUB-001 的要点是 `给出最大横断面二维尺寸（15 mm × 13 mm）` → **不命中**，不扣

**结论：同样的能力位，有的样本扣分、有的不扣 —— 因为判据是"措辞像不像关键词"，不是"这个子项能不能评"。** 这是当前实现最实质的缺陷。

### 附带发现：AI 抽取的要点质量参差

`SEU-001` 的 `FIND-06`（密度/信号/强化程度）里放的要点是 `提及病灶紧贴膈面` ——
那是**位置**描述，跟"密度"没关系。说明抽取提示词对"条目语义边界"约束不够，会串条目。

## 四、如果直接去掉能力位，会发生什么

| 做法 | 后果 |
|---|---|
| 只删能力位模块、分母固定 100 | 每个学员在 `GEN-02`(1) + `IMP-05`(4) + `IMP-08`(4) 上被按 0 分算，再叠加 `FIND-04` 的不确定 → **白丢 9–13 分，写得再好也到不了 100**。学员会问"我写得完美为什么只有 87 分" |
| 删模块 + 在评分表里手工把这些条目标"不适用" | 分数上等价于现在。但：**工作量更大**（每题要手工标 3–4 条，而不是勾 3 个位）、**没有一致性保障**（换个老师标法就不同）、**容易退回"整条剔除"**（那正是当初要修的不公平：学员写对了 `FIND-06` 的"密度=实性"还会因为"强化"评不了而整条丢分） |
| 删模块 + 从 R1 表里删掉这些条目 | R1 表是院方的《放射科-诊断报告书写质量评价表》，改表会破坏与院方标准的可比性；且将来接上测量工具/既往片/增强序列时，又要改回来 |

## 五、建议：留着，做两件实事

### 5.1 面板瘦身：5 位 → 3 位

| 现在 | 建议 | 理由 |
|---|---|---|
| 测量工具（只读） | **移出面板**，改成卡片下方一行只读状态 | 它由**影像控件**决定、恒 false，放在"能力位"里容易让人以为可以勾 |
| 既往检查影像 | 保留 | 将来接了既往片对比就有用 |
| 增强期相序列 | 保留 | 唯一当前有区分的位 |
| 肿瘤病例 + 临床含分期依据 | **合并成一位**「临床已提供分期依据」 | 两个分支对分数**完全等价**，合并零损失；理由文案可后续再细化 |

### 5.2 修规则：不再靠要点文字正则匹配

改为**在要点上直接存一个可评性标签**，由 AI 抽取时一并产出：

```js
{ id:'p2', text:'描述强化程度', accept:[...], assess:'enhance' }   // enhance | measure | prior | staging
```

`resolveRubric` 按标签查能力位，**必中**，不再依赖措辞。这样能直接消灭第三节那三个问题。

### 5.3 附带治一下要点质量

抽取提示词里补"**要点必须落在本条目的语义范围内**"，并在管理端保留逐条校正（已经有了）。
必要时对 16 例的要点做一轮人工过一遍——这是"能否作为考核依据"的前置条件。
