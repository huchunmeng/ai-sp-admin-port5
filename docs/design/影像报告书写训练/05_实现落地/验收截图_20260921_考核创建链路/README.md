# 验收截图 · 考核创建链路（2026-09-21）

> 「考试怎么创建」这条链路打通后的验收证据。截图由 Playwright 真实浏览器操作产生，不是设计稿。

## 1. 这条链路是什么

管理端创建 → 学员端看到 → 作答 → 成绩入库。**组卷不新建页面**，复用平台已有的 OSCE 考试流程，
影像报告书写在其中是一个**考站类型**：

```
管理端 /station-settings   添加考站类型 → 一键「影像报告书写站」（时长 20 分 + 自动绑定影像报告评分表模板）
        ↓
管理端 /exam-create        四步向导 → 考站设置里给影像站选影像病例 + 设考核配置（考试方式/题量/达标线/
                           出分时机/可见内容/重考策略/满分口径，含三套预设）→ 提交
        ↓
跨端持久化                 packages/shared/data/created-exams.json（dev 中间件 /api/created-exams）
        ↓
学员端 /report-writing/exam-tasks   「我的考核任务」读到该任务（页脚标「已接入考核配置」）
        ↓
学员端 /report-writing/exam?task=…  按任务配置出卷作答 → /exam-records 台账
```

## 3. 已知未做（照实记录，别当已完成）

1. **达标线口径有一处不一致**：任务配置的 `passLine`（老师填的）用于列表与须知展示；
   **达标/未达标徽标**用的是评分结果自带的难度标定线。两者默认相同，**老师手改后才会分叉**。
2. **题量未校验**：配置块允许填的题量大于已选病例数；出卷按 `caseIds.length`，不读 `questionCount`。
3. **仍未接真服务端**：`created-exams` 走 dev 中间件写 JSON，接口不通才降级 localStorage；
   生产必须换后端 API。时间可信 / 答卷入库 / 防重考原本就需要服务端。
4. **没有考生维度**：一次考核只产出 1 条任务/场次，尚未按名单给每个考生派发。
5. **影像站只能建在机构方案上**：平台/省级方案的编辑不落库（`mergeEdits` 对非 institution 只合并 status），
   且机构方案原本没有「放射科」专业，需先添加专业再建站。
6. 页面控制台有 3 条 500，是既有 vite 代理到未启动的后端 mock（`ECONNREFUSED`），与本次无关；
   新端点 `/api/created-exams` 两端均 200。

## 4. 复现

```
管理端  http://localhost:5002/#/station-settings   → 编辑（机构）方案 → + 添加考站类型 → 影像：影像报告书写站
管理端  http://localhost:5002/#/exam-create        → 四步向导（考站设置里选影像病例 + 配考核配置）
学员端  http://localhost:5001/#/report-writing/exam-tasks
```
