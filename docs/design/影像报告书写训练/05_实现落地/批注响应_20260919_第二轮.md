## 二、AI伴学怎么实现的（这是本轮最实的一块）

**数据源换了，不是换了套皮。** 流程走的是仓库既有的 `/api/llm` 代理（`apps/training/vite.config.js` 的 `llm-proxy`，本期配置为 `qwen-turbo`），复用既有 `useAIChat`：

```
学员点「L2/L3」
  → 【受理即原子预扣】校验配额与冷却 → 扣减 → 写冷却（同一同步块，不留空窗）
  → 组装 prompt：system 写角色与铁律 + user 放【参考报告（题目答案）】+【学员已写的该段】
  → 调 /api/llm
  → 【出站红线校验】与金标准最长公共子串 ≤ 8 · 不得命中金标准的测量值与具体征象词
      ├─ 通过 → 展示提示（附红线结果留痕）
      └─ 不通过 / 模型失败 → 丢弃 → 展示固定降级文案 → **退还配额与冷却**
```

**L1 不调模型**——它是纯体裁知识（"这一段规范上应包含哪些要素，不涉及本病例"），走静态库反而确定性更高、零成本、零泄漏风险。只有 L2/L3 需要读题目答案，才调模型。

**红线实现到什么程度（照实说）**：

| 项 | 状态 |
|---|---|
| 红线 A：与金标准全文最长公共子串 ≤ 8 | ✅ 已实现（PRD §9.5） |
| 红线 B2：不得命中金标准的**测量值**（`12mm`/`10mm`）与**具体征象词**（分叶/毛刺/胸膜牵拉/实性/肿大淋巴结…） | ✅ 已实现（词表=只在金标准中确实出现的才纳入） |
| 红线 B1：诊断结论短语的**自动抽取** | ⚠️ **未实现**，靠红线 A 兜底（复述结论必然触发 ≥8 字连续片段，单测已验证） |
| 泛化体裁词不误拦（PRD §9.5 明确要求） | ✅ 已验证「部位与范围、数目与大小」放行 |
| 校验位置 | ⚠️ 本期放在**前端**兜底；正式版须在**服务端出站层**，并写 `hintAudit.redlineCheck` |

**已知缺口**：**改写措辞复述结论**可绕过 B1（红线 A 只抓连续片段）。需按 PRD §12 场景 16 构造对抗样本回归后再定标。

### 配额回滚实测
