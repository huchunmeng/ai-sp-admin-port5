## 四、批注 3：报告结构要改（**先确认再动手**）

你的原话拆开是：

```
四段式报告填写：临床情境引导 + 三阶段影像报告训练
  第一段：患者临床信息 直接给出
  第二段：临床目的 可以让学生填 + 检查方法
  第三段：影像所见
  第四段：诊断意见
```

### 我的读法

| 段 | 内容 | 谁写 |
|---|---|---|
| 一 | 患者临床信息（性别年龄 + 病史） | **系统直接给出**（学生不用写）→ 这就是「**临床情境引导**」 |
| 二 | 临床目的 + 检查方法 | **学生写** |
| 三 | 影像所见 | 学生写 |
| 四 | 诊断意见 | 学生写 |

→ **学生实际写 3 段 = 「三阶段影像报告训练」**；报告仍是四段，但第一段是题面情境。
与现在（学生写 一般信息 / 检查技术 / 影像所见 / 诊断意见 四段）的差别是：
**「一般信息」段不再由学生写**；**「检查技术」并入第二段的"检查方法"**。

### 需要你定的一点（其余我都能推出来）

**第一段"直接给出"之后，原来挂在"一般信息"段上的分怎么算？**

现在 R1 表维度一有 13 分靠这一段：`GEN-01` 患者信息 2 分 + `GEN-03` 检查时间 1 分 + `GEN-04` 临床主要信息及检查目的 10 分。
第一段变成系统给出后：

| 选项 | 结果 |
|---|---|
| **A（推荐）** | `GEN-01`/`GEN-03`（患者信息、检查时间）**转为不可评**，`GEN-04`（临床主要信息及检查目的）**落到第二段**照旧评 | 每例可评满分 −3（PUB-001 **87 → 84**，低于组卷下限 85） |
