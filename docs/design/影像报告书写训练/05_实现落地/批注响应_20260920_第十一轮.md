## 二、四个提问的答案

### 批注 1：图片要不要分视图导入？包里能不能区分位置？

- **必须分开导**：一个病例的影像本来就是**多套不同的图**——胸部 CT 是 `肺窗` 与 `纵隔窗` 两套（同一批层面、两套窗宽窗位），
  颅脑 MR 是 `DWI / ADC / T2WI / FLAIR` 几套。它们不是"同一套图的不同视角"，是**不同的序列**，训练时要分开翻层。
- **但旧实现确实区分不了**：解包时用了 `f.name.split('/').pop()`，把文件夹路径**丢掉了**，所以一个包里就算有 5 个序列文件夹，
  也只能整体塞进当前视图。你的疑问是对的。
- **已改进**：包里有 **≥2 个顶层文件夹**时，按文件夹自动分配——**视图名相同的直接并入，没有的自动新建视图**。
  实测：`肺窗轴位/`(3 张) + `纵隔窗轴位/`(2 张) → 并入现有两个视图（75→78 / 75→77）；
  `SER1/` + `SER2/` → **自动新建两个视图**（2 帧 / 1 帧）。单文件夹的包行为不变（仍进当前视图）。

### 批注 2 + 3：`测量工具` 为什么不删、整条「本卷条件」看不懂

- **它原来的作用**：`FIND-04` 有一条要点是"给出病灶大小实测值"，而**本期影像控件没有测量工具** →
  这条要点判不了 → 从这道题的分母里剔掉，成绩显示"本卷可评 87"而不是硬按 100 算。
  「测量工具」那一行就是用来解释**为什么这几条不计分**的。
- **为什么你看不懂**：因为我把**机器条件**直接摊给了老师看。`增强期相序列 / 既往检查影像 / 肿瘤病例` 这三个词是从
  `R1 条目 → 依赖条件` 反推出来的抽象中间层，**老师脑子里没有这个概念**——他只关心"我这一条要点算不算分"。
- **所以整条删掉了**，改成**在结果处告知**：不评的要点，在自己的 `评分规则` 格子里写一行
  `本题条件不足，不评（原因）  改为参评`。要改判就点那个链接（实测：点一下「本卷可评」87 → 89）。
  这样"为什么不计分"和"怎么改"都出现在老师正在看的那一行，不需要先理解一套体系。

### 批注 4：`恢复内置` 是干什么的

它丢弃本页改动、回到题库里存的那一版。样机里题库那一版就是**「AI 从标准报告抽取」生成的初版**，所以它等于
"撤销我改乱的，回到 AI 初稿"。已改名 **`还原初始评分表`** 并补了悬停说明。
（与右边那个「AI 从标准报告抽取」的区别：抽取会**重新调用模型**生成一份新稿，两者结果可能不同。）

## 三、多文件夹 zip 自动分视图（批注 1）

```
包内结构                         结果
序列A/1.jpg 2.jpg 10.jpg   →    视图「序列A」：并入（已有同名视图）或新建
序列B/1.jpg 2.jpg          →    视图「序列B」：并入或新建
单层散图（无文件夹）        →    行为不变，进当前视图
```

- 视图名取**文件夹名**；同名视图直接并入（去重 + 自然序重排），没有则新建
- 仍受单视图 300 帧、单张 5 MB 上限；超过 8 个文件夹时不拆（避免误操作生成一堆视图），退回"整体进当前视图"
- 完成后提示：`压缩包内 N 个文件夹，已按文件夹分到 N 个视图（新建 M 个）`

## 四、评分表新结构（批注 5–9）

```
维度 | 条目（含整条判定说明） | 分值 | 评分要点 | 要点分值 | 评分规则（含可接受表述） | 操作
```

### 引入「要点分值」——评分口径随之改为**逐要点加权**

| 项 | 原 | 现 |
|---|---|---|
| 分值来源 | 条目满分 × (可评要点数 / 要点总数) | **Σ 各要点分值**（可评的要点才计入） |
| 要点分值默认 | — | R1 条目满分**均分到 0.5**，余数补给最后一个要点：`4 分 2 点 → [2,2]`、`2 分 3 点 → [0.5,0.5,1]`、`10 分 3 点 → [3,3,4]` |
| 得分 | 条目可评满分 × (命中档之和 / 可评要点数) | **Σ(该要点命中档 × 该要点分值)** |
| 一致性 | — | 要点分值之和 ≠ R1 标称时，分值格标红 `≠10` 提示 |

**这是好事**：原来"每个要点权重相同"是我在代码里默认的，现在**权重显式可调**，和病例编辑器的评分表（有「评分项分值」与「要点分值」两级）口径一致。
**全库自检**：`resolveRubric` 下 23 个条目的 `full` 合计仍为 **100**，各样本可评满分不变（PUB-001 = 87、SEU-001 = 91）。

### 评分规则真的进评分

`buildScoringPrompt` 现在对每个可评要点给出：**要点分值 · 可接受表述 · 判定规则**，模型据此判定；
抽取提示词也新增"每条要点给一个 rule"，所以 AI 抽出来的规则开箱可用、老师再改。
