#6 原话：「`可评条件` → 这一列不要用可评分条件，改为**评分规则**，直接 LLM 生成，可手动编辑，供 LLM 评分使用」。

因为那 16 例的评分表是**引入 `rule` 字段之前**抽的，模型从没生成过它。你打开看到的是一列空文本框，
自然会再标一次。

**已补：**
- 新增 `packages/shared/data/imaging/rubric-rules-ai.js`（自动生成）：**逐要点 AI 补写评分规则**，
  每例一次调用、只补 `rule`，**不动要点文案 / 可接受表述 / 可评条件**，避免重抽把已校对过的要点冲掉
- `resolveRubric` 取值顺序：**要点自身的 `rule` → `AI_RULES` 里补写的 → 空**
- 以后新抽取的评分表会**自带** `rule`（抽取提示词已加这条），补写文件只服务这 16 例老数据
