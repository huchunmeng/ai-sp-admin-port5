## 3. 顺带发现并修掉的两个问题

**a. 考试页有「重新评分」按钮（诚信漏洞）**
`ScoreResultPanel` 底栏原本无条件给「重新评分」，学院端考试页也能点 ——
**能反复重评等于能一直重掷到过线**。现在加 `allowRescore`（默认 true）：

- 考核侧三处传 `false`：考试室内联报告、考站机成绩报告、管理端成绩管理明细；
- **训练侧保持默认（保留重新评分）**；「申请复核」在所有场景都保留（符合 R3 留痕）。

**b. 深链进考试室时不知道自己已交卷**
换设备或清了本地存储后，直接打开 `?task=xxx` 会显示"考试须知"而不是成绩（旧实现只看本地存储）。
新增**服务端优先恢复**：从服务端取回该考生这份会话再走既有状态机
（已交卷→成绩页 / 未到点→续答），服务不可达时退回本地。实测深链已交卷任务 → `phase: done`、内联成绩正常。
