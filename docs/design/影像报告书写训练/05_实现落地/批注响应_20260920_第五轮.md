## 二、成绩报告：从独立页面改回弹窗

第四轮按"提交后直接给出成绩报告"做成了**独立路由页** `report-writing/train/:caseId/result`。本轮定：**做成弹窗**，理由是它本质是"这一次提交的结果"，不该占一个 URL、也不该让人"退出成绩页"才能接着改。

| 项 | 第四轮 | 本轮 |
|---|---|---|
| 形态 | 独立路由页（无壳页） | **弹窗**（`ScoreReportModal.vue`，1180px 宽 / 92vh，内部滚动） |
| 打开方式 | 提交 → `router.push` | 提交 → **原地弹窗**；训练记录页点「成绩报告」也打开同一个弹窗 |
| 顶部 | 站点顶栏（中=成绩报告） | 弹窗标题条：`成绩报告 · 病例标题 · 提交时间` + 关闭 |
| 底部操作 | 返回修改 / 重练 / 完成（页脚） | **同一组按钮移进弹窗页脚** |
| 路由 | `report-writing/train/:caseId/result` | **删除**（`ReportWritingResult.vue` 一并删除） |
| 数据来源 | 共享同一份会话实例 | 弹窗接受 `scoring / draft / sample` 三个 prop——**工作台传自己的会话，训练记录传那一条历史记录**，同一组件两处复用 |

弹窗内部仍是两块：`ScoreResultPanel`（大分 + 五维条 + 逐条要点 + 缺失汇总 + 重新评分 / 申请复核）+ `ComparePanel`（你的报告 vs 参考报告 + 本卷不计入的条目）。

> **为什么弹窗化之后反而更省事**：第四轮为了让成绩页拿到分数，专门给 `useReportSession` 加了按 `caseId` 缓存的单例（跨页共享响应式状态）。改成弹窗后**不再需要跨页传递**，那份单例留着无害、也不再是必需。

## 三、训练记录（新增页面 + 三个入口）

### 数据

新增本地键 `report_writing_records_v1`，**每一次「提交报告」落一条**：

```js
{
  id, caseId, title, bodyPart, modality, level,
  round,                 // 第几轮（重练 +1）
  submittedAt,           // 'YYYY-MM-DD HH:mm'
  status,                // pending 评阅中 / done 已评分 / failed 评分失败
  score, scoreableMax,   // 得分 / 本卷可评分
  result,                // composeScore 的完整结果（逐条要点 + 点评语），供历史回看
  draft                  // 这次提交的四段报告原文，供对照区使用
}
```

提交时先写 `pending` 并把 `result` 留空，评分回来后**回填**同一条（`upsertPracticeRecord`）。所以记录页能看到"评阅中…"并自动变成分数。

`useReportSession` 新增导出：`readPracticeRecords()` / `readPracticeRecord(id)` / `clearPracticeRecords()`。

### 页面 `ReportWritingRecords.vue`（路由 `report-writing/records`）

- 顶部统计：**提交次数 / 练过病例 / 平均得分**
- 筛选：病例下拉（从已有记录聚合）+ 状态（已评分 / 评阅中 / 评分失败）+ 名称搜索
- 表格：`提交时间 / 病例（标题 + 编号）/ 部位·模态 / 难度 / 得分 / 轮次 / 操作`
  - 得分按 `>= 85` 主色、否则橙色；评阅中显示斜体"评阅中…"
  - 操作：**成绩报告**（开弹窗）、**重练**（进该病例工作台）
- 空态：一句"还没有训练记录，去写一份报告吧" + 去训练按钮（不写说明性长句）

### 三个入口

| 位置 | 形态 |
|---|---|
| 模块首页 `report-writing` | 第三个入口卡「训练记录」（提交次数作为脚注），首页入口由 2 列改 3 列 |
| 训练病例列表 `report-writing/train` | 筛选栏最右一个「训练记录」按钮 |
| 工作台 | 提交后自动弹出成绩报告，弹窗内即为记录内容；关掉弹窗仍在工作台 |

面包屑已加 `首页 / 影像报告书写训练 / 训练记录`。
