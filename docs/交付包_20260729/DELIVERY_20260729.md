## 二、开发者重点关注的文件

### 登录

看 `apps/training/src/router/index.js` L44-49 的 beforeEach 守卫，以及 `apps/training/src/stores/user.js` 的 login/logout 逻辑。登录页 UI 在 `LoginView.vue`。

### AI 伴学

核心是 `AICompanionDrawer.vue`（559行），关注三个函数：
- `buildSystemPrompt()` — 拼装 LLM 上下文
- `askQuestion()` — 用户提问流程
- `suggestedQuestions` — 按考站类型的建议问题

底层调 `useAIChat.js` → `POST /api/llm`。开发环境 LLM 代理在 `apps/training/vite.config.js` L260-341。

### 专家点评

管理端：`ExpertKBEditor.vue` → 编辑表单 → CaseEditor 保存为 `{caseId}-expert.json`
训练端：`AICompanionDrawer.vue` 专家点评 Tab → `loadExpertData()` 加载 JSON → `generateExpertReview()` 调 LLM 生成

### 精品病例标签

`source` 和 `caseLevel` 存储在 `{caseId}-basic.json` 顶层。管理端 CaseEditor 两个下拉框 → `persistMeta()` → `POST /api/case/save-fields`。所有 7 个 case-index API（vite.config.js x4 + ai-gen-plugin + mock-gen + prod-server x2）都必须输出这两个字段。

## 三、注意事项

1. LLM API Key 在 `.env.local` 配置，未配置时 /api/llm 返回 503
2. AICompanionDrawer 仅在考站页面显示（`isStationRoute=true`）
3. 专家点评是手动触发生成，非自动
4. useAIChat 30 秒超时，失败返回中文兜底文案
5. 开发/生产环境的 LLM 代理分别维护（vite.config.js vs prod-server），逻辑一致
6. case-index API 在 7 个位置，新增字段必须全部同步
