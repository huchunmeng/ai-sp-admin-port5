## 二、登录系统

### 2.1 登录页

- 手机号 + 密码 + 图片验证码 + 用户协议勾选
- 背景使用 `/images/login-bg.png`
- 登录成功后 userStore 持久化到 localStorage

### 2.2 路由守卫

```js
router.beforeEach((to, from, next) => {
  if (to.name === 'login') return next()
  if (!userStore.isLoggedIn) return next({ name: 'login' })
  next()
})
```

### 2.3 退出登录

点击 header 用户名 → 下拉菜单 → "退出登录" → 清除 localStorage → 跳回登录页。点击空白处关闭菜单。

## 三、AI 伴学 — 智能问答

### 3.1 入口

考站训练页面右侧浮动圆形按钮（AI学伴头像），点击展开 400px 宽侧边面板。

### 3.2 显示范围

仅在考站训练页面显示（isStationRoute=true）。首页、病例列表、病例详情、成绩报告、MDT 讨论页均不显示。

### 3.3 System Prompt 组装

每次提问时动态构建：临床教学助手人设 + 病例信息（姓名/性别/年龄/主诉/疾病/科室）+ 当前考站 + 最近 8 条 SP 对话记录。

### 3.4 建议问题

根据考站类型显示不同建议（如病史采集→"接下来应该问哪些问题？"，诊断→"最可能的诊断是什么？"）。

### 3.5 异常处理

- 断网/超时 → "抱歉，网络异常，请稍后再试。"
- API Key 未配置 → "抱歉，AI服务暂时不可用，请稍后再试。"
- 30 秒超时 → "抱歉，请求超时，请稍后再试。"

## 四、专家点评

### 4.1 管理端 — 专家知识库

病例编辑器 → "专家知识库" Tab → ExpertKBEditor 表单：

| 字段 | 说明 |
|------|------|
| 启用专家点评 | 勾选框 |
| 专家姓名 | 如"滕皋军 院士" |
| 专家单位/职称 | 如"东南大学附属中大医院 · 介入与血管外科" |
| 点评标题 | 如"Graves病鉴别诊断中的关键线索" |
| 标签 | 逗号分隔 |
| 专家知识库内容 | 500-2000字领域知识 |

保存为 `{caseId}-expert.json`。

### 4.2 训练端 — 点评生成

切换专家点评 Tab → 加载 `{caseId}-expert.json` → 三种状态：
- **加载中**: spinner
- **无数据**: "该病例暂无专家点评"
- **有数据**: 专家信息卡片 + "生成专家点评"按钮

System Prompt：顶级临床专家人设 + 病例信息 + 专家身份 + 知识库全文 + 最近 10 条学员操作记录 → 输出学员表现分析/知识点讲解/改进建议。

### 4.3 学员追问

点评正文生成后，下方出现追问输入框，System Prompt 包含之前的点评全文 + 知识库，支持多轮。

## 五、精品病例标签 + VR入口 + UI调整

### 5.1 精品病例标签

| 字段 | 可选值 | 存储 |
|------|--------|------|
| `source`（精品来源） | 院士精讲 / 金牌导师 / 国家级质控中心 / 空 | `{caseId}-basic.json` |
| `caseLevel`（难度标签） | 基础病例 / 高阶病例 / 疑难病例 / 空 | `{caseId}-basic.json` |

管理端 CaseEditor 两个下拉框编辑 → 自动保存。训练端列表卡片角标显示、首页推荐/学习记录显示、来源筛选。

### 5.2 VR研习空间

首页精品病例右侧"VR研习空间"卡片 → 点击进入**独立页面**（路由 `vr-lab`，`VRLab.vue`），页内两个项目：

1. **磁共振成像原理与序列应用虚拟仿真实验**（国家级一流本科课程）：简介（4 个递进实验模块 + 课程影响力数据）+ 配图 + 「进入课程」按钮，新标签页打开 `https://xnfz.seu.edu.cn/exp/272.html`
2. **VR脑解剖图谱教学**：简介（三维结构模型 + 体绘制影像 + 多切面观察）+ 两张静态图片

简介文案与两张脑解剖配图取自《VR研习空间.docx》（中大医院信息中心项目资料）。

### 5.3 UI调整

- MDT卡片 badge: "即将开放"（替代"3 例可讨论"）
- 在线考试卡片: 点击弹出 toast "在线考试功能即将开放，敬请期待"，不跳转

## 七、LLM 调用路径

```

  → 开发环境: vite.config.js llm-proxy 中间件
  → 生产环境: prod-server /api/llm 路由
  → LLM_API_URL (env: LLM_API_KEY / LLM_API_URL / LLM_MODEL)
```
